# 속삭이는 숲 (Whispering Woods)

숲을 치유하며 어둠에 맞서는 **3D 힐링 서바이벌 PC 게임**입니다. 🌲👻

## 🎯 프로젝트 소개

기억을 잃은 유령이 되어 숲의 생명력을 회복시키고 어둠의 세력을 물리치는 3인칭 힐링 서바이벌 게임입니다. 평화롭고 치유적인 분위기 속에서 나무를 되살리고 악의 꽃을 제거하며, 생존의 긴장감과 함께 숲의 평화를 되찾는 15~30분 분량의 여정을 제공합니다.

* **장르 / 플랫폼**: 힐링 서바이벌 (3인칭 시점) / PC (싱글 플레이어, Play time: 15~30분)
* **팀원 구성**: 개인 프로젝트 (1인 개발)
* **진행 방식**: GitHub Desktop을 활용한 코드 및 버전 관리

## 👩🏻‍💻 담당 역할

기획부터 아트 리소스 수급, 프로그래밍 전반까지 **프로젝트 전체 과정을 1인 전담**하여 제작했습니다.

* **게임 기획 & 메커니즘 설계**: 세계관 구축 및 승급 프로젝트 기획, 핵심 생존·치유 루프 설계
* **프로그래밍 & 상태 제어**: 
  * 다양한 상호작용 로직 구현 (버섯 섭취 체력 회복, 나무 육성, 악의 꽃 제거 등)
  * 시간 경과에 따른 자연스러운 낮/밤 환경 연출 및 상호작용 UI/UX 구축
* **아트 & 비주얼**: Unity 에셋 활용 및 생성형 AI(ChatGPT)를 통한 리소스 수급 및 편집

## 🖥️ 사용 기술

- **Engine & Language**: Unity 3D, C#
- **VCS**: GitHub, GitHub Desktop

## 🌱 성장 경험

- **1인 게임 개발 전 과정 완수**: 기획, 아트, 프로그래밍 전반을 스스로 다루며 게임의 전체적인 시스템 구조를 설계하고 구현해내는 통합 개발 능력을 키웠습니다.
- **Unity 상태 제어 및 상호작용 시스템 구축**: 체력, 식생 성장, 오브젝트 상태 변환 등 다양한 요소를 효율적으로 관리하는 코드를 작성하며 인게임 시스템 구성 역량을 강화했습니다.
- **디테일한 연출을 통한 몰입감 향상**: 낮과 밤의 자연스러운 흐름 연출과 직관적인 상호작용 UI 구현을 통해 힐링 서바이벌 장르 특유의 분위기와 visual 완성도를 높였습니다.
